## Objetivo

Traduzir conteúdo textual curto (descrições de animes) enviado pelo cliente através de uma porta desacoplada (`TranslationProvider`) e de um adapter HTTP inicial para LibreTranslate self-hosted (conforme [ADR-012](../adr/ADR-012-libretranslate-com-adapter-substituivel.md) e [ADR-013](../adr/ADR-013-cliente-envia-descricao-para-traducao.md)), com endpoint autenticado `POST /api/v1/translations`, normalização rigorosa de texto e quebras de linha, política explícita de HTML, tratamento tipado de falhas externas (timeout, indisponibilidade, quota), proteção absoluta de credenciais e de conteúdo textual sensível em logs e telemetria, e cobertura por testes controlados sem consumo de quota externa no CI.

A sprint entrega a primeira fatia vertical ponta a ponta de tradução em ambiente controlado, sem cache nem persistência de traduções em banco; cache, chave canônica, quotas e retenção pertencem à Sprint B3.2, que consolidará e encerrará o **Marco M3 — Tradução controlada**.

## Dependências e Definition of Ready

- O Marco M2 (Sprints B2.1, B2.2 e B2.3) está concluído e aceito na branch `master`.
- A infraestrutura de segurança e autenticação JWT de Identity está operacional; o endpoint `POST /api/v1/translations` exige access token JWT válido (`@PreAuthorize("isAuthenticated()")`), utilizando o `SecurityFilterChain` e o conversor de claims existentes.
- O contrato HTTP vigente é `docs/api/openapi.yaml` (versão 0.4.3) e já especifica o endpoint `POST /translations` com `TranslationRequest`, `TranslationResponse`, schemas e códigos de erro (`200`, `400`, `401`, `429`, `502`, `504` e `500`); implementação, DTOs, validações e testes devem manter conformidade estrita com o contrato.
- O [ADR-012](../adr/ADR-012-libretranslate-com-adapter-substituivel.md) está aprovado e define LibreTranslate self-hosted com motor Argos como provedor inicial, acessado por HTTP através da porta `TranslationProvider`, com isolamento total do domínio e suporte a `FakeTranslationProvider` em ambiente local e testes.
- O [ADR-013](../adr/ADR-013-cliente-envia-descricao-para-traducao.md) está aprovado e estabelece que o cliente envia a descrição já obtida da AniList (sem consultas pelo backend); `source` é metadado opcional não confiável; payload suporta `en`, `ja`, `auto` como `sourceLanguage`, `pt-BR` como `targetLanguage`, e `ANIME_DESCRIPTION` como `contentType`.
- O [ADR-014](../adr/ADR-014-politica-de-retencao-e-exclusao.md) está aprovado e veda terminantemente a persistência do texto original enviado para tradução, bem como o registro de texto integral em logs, métricas ou traces.
- O catálogo de erros `docs/api/catalogo-de-erros.md` e o enum `ProblemCode` já definem os códigos estáveis `translation_provider_failed` (502) e `translation_provider_timeout` (504).
- O módulo Spring Modulith `translation` já possui sua fronteira declarada em `package-info.java`, permitindo dependências apenas para `identity :: api` e `shared`.

## Sequência de execução

1. **B3.1-T1:** Estruturar os pacotes do módulo `translation` (`domain`, `application`, `infrastructure`, `web`), modelar os tipos de domínio (`Language`, `ContentType`, `TranslationSource`, `NormalizedText`, `TranslationResult`), declarar a porta `TranslationProvider`, implementar o `FakeTranslationProvider` e criar o teste de contrato compartilhado da porta.
2. **B3.1-T3:** Implementar o normalizador de conteúdo (`ContentNormalizer` / `TranslationPolicy`) cobrindo Unicode NFC, quebras de linha (`\r\n` -> `\n`), controle de whitespace e a política de HTML (tags seguras de formatação `<br>`, `<p>`, `<b>`, `<i>`, `<em>`, `<strong>` permitidas; scripts, iframes e atributos executáveis rejeitados com validação).
3. **B3.1-T4:** Implementar o `LibreTranslateProviderAdapter` usando `RestClient`, com timeouts de conexão e leitura configuráveis, tratamento de status HTTP externos e mapeamento tipado para as exceções da porta `TranslationProvider`.
4. **B3.1-T5:** Proteger propriedades de configuração (URL e API key do provedor) com mascaramento e implementar sanitização estrita de telemetria e logs (nenhum texto integral nem segredo registrado).
5. **B3.1-T2:** Implementar DTOs de entrada e saída, o caso de uso `TranslateContentUseCase` e o controller HTTP `POST /api/v1/translations`, configurando proteção via Bearer JWT e mapeamento de exceções em `ApiExceptionHandler`.
6. **B3.1-T6:** Cobrir a fatia HTTP com testes de integração (`@WebMvcTest` ou `@SpringBootTest`), testar cenários de sucesso, token ausente, payload inválido, timeout simulado e falha externa via `MockRestServiceServer`, e validar fronteiras modulares com Spring Modulith.
7. **Gate e encerramento:** Executar o gate completo `.\gradlew.bat check --no-daemon --stacktrace`, documentar evidências e preparar a transição para a Sprint B3.2.

## Critérios de aceite

- [ ] A porta `TranslationProvider` está declarada em `translation.application.ports` e desacopla integralmente o domínio de SDKs, DTOs e detalhes HTTP de fornecedores.
- [ ] `FakeTranslationProvider` está implementado e disponível para ambientes de teste e desenvolvimento local sem necessidade de serviço LibreTranslate ativo.
- [ ] `LibreTranslateProviderAdapter` implementa `TranslationProvider` consumindo a API HTTP do LibreTranslate (`POST /translate`), transmitindo `q`, `source`, `target`, `format` e `api_key` (quando configurada).
- [ ] `POST /api/v1/translations` exige access token JWT válido; chamadas sem credencial ou com token expirado/inválido retornam `401 AuthenticationProblem`.
- [ ] `POST /api/v1/translations` valida sintaticamente o payload: `text` (1 a 10.000 caracteres), `sourceLanguage` (`en`, `ja`, `auto`), `targetLanguage` (`pt-BR`), `contentType` (`ANIME_DESCRIPTION`) e `source` opcional (`system` 1..64, `externalId` 1..128).
- [ ] Requisições com campos ausentes ou inválidos retornam `400 ValidationProblem` com código estável `request_validation_failed` e `errors[]` indicando os campos rejeitados.
- [ ] O texto é normalizado em Unicode NFC, com quebras de linha uniformizadas e sem remoção de conteúdo semanticamente relevante.
- [ ] A política de HTML aceita tags seguras de formatação usadas por descrições AniList (`<br>`, `<p>`, `<b>`, `<i>`, `<em>`, `<strong>`) e rejeita elementos maliciosos (`<script>`, `<iframe>`, atributos executáveis) com `400 ValidationProblem`.
- [ ] Requisições válidas com tradução bem-sucedida retornam `200 OK` com `translation`, `sourceLanguage` (resolvido/detectado), `targetLanguage`, `contentType` e `cached: false`.
- [ ] Timeout na comunicação com o provedor externo retorna `504 Problem Details` com código estável `translation_provider_timeout`.
- [ ] Indisponibilidade, erro 5xx ou falha de conexão com o provedor externo retorna `502 Problem Details` com código estável `translation_provider_failed`.
- [ ] Nenhuma chave de API, credencial ou texto integral submetido para tradução é emitido em logs (INFO, WARN, ERROR) ou telemetria em qualquer camada.
- [ ] Testes automatizados do adapter utilizam `MockRestServiceServer` / `MockWebServer`, garantindo que o CI execute 100% isolado da rede externa.
- [ ] Os testes arquiteturais do Spring Modulith garantem que o módulo `translation` respeita os limites modulares, sem acessar detalhes internos de outros módulos.
- [ ] O gate completo `.\gradlew.bat check --no-daemon --stacktrace` passa sem erros (compilação, testes, ktlint, Detekt, Kover e OpenAPI lint).

## Decisões

- **D-B3.1-1: Provedor inicial e porta substituível:** Em conformidade com o [ADR-012](../adr/ADR-012-libretranslate-com-adapter-substituivel.md), o domínio depende unicamente da interface `TranslationProvider`. O adapter inicial conecta-se via HTTP ao LibreTranslate. Ambientes de teste e desenvolvimento local podem utilizar `FakeTranslationProvider`.
- **D-B3.1-2: Descrição enviada pelo cliente:** Em conformidade com o [ADR-013](../adr/ADR-013-cliente-envia-descricao-para-traducao.md), o cliente KMP envia o texto que já possui; a API não se conecta à AniList para buscar descrição por ID. O metadado `source` é opcional e não confiável.
- **D-B3.1-3: Política de HTML:** Descrições de animes provenientes da AniList contêm formatações básicas em HTML (`<br>`, `<p>`, `<i>`, `<b>`). A normalização aceita um conjunto estrito de tags seguras de formatação textual e rejeita tags ativas/perigosas (`<script>`, `<iframe>`, `onclick`, etc.) com `400 ValidationProblem`. Ao chamar o LibreTranslate com conteúdo contendo tags permitidas, o parâmetro `format` é enviado como `"html"`, preservando a marcação estrutural; caso contrário, é enviado como `"text"`.
- **D-B3.1-4: Ausência de cache e banco em B3.1:** A Sprint B3.1 foca na tradução funcional sem cache. A resposta HTTP sempre retorna `cached: false`. Nenhuma migration Flyway para criação de tabela de traduções é introduzida em B3.1; a tabela `translation.translations`, a chave lógica SHA-256 e a quota pertencem à Sprint B3.2.
- **D-B3.1-5: Cliente HTTP via Spring RestClient:** O adapter `LibreTranslateProviderAdapter` utiliza o `RestClient` moderno do Spring Framework (Spring Boot 4), com fábrica de requisições configurada para timeouts estritos de conexão (ex: 2s) e de leitura (ex: 5s), permitindo testes herméticos via `MockRestServiceServer`.

## Bloqueios e riscos

| Risco | Probabilidade/Impacto | Mitigação | Gatilho de revisão |
|---|---|---|---|
| LibreTranslate alterar ou corromper tags HTML na tradução | Média / Alta | Testes unitários com fixtures reais de descrições AniList contendo `<br>`, `<i>`, `<b>` avaliando a preservação estrutural | Relato de quebra de layout no app KMP |
| Vazamento acidental do texto traduzido ou de chave de API em logs | Média / Alta | Teste automatizado de asserção de log verificando que nenhum texto integral ou credencial é capturado pelo logger | Log de exceção contendo corpo de requisição HTTP |
| CI falhar por dependência de rede externa | Baixa / Alta | Uso obrigatório de `MockRestServiceServer` ou `FakeTranslationProvider` em todos os testes automatizados | Qualquer tentativa de socket real para fora em CI |
| Latência cumulativa em retries | Baixa / Média | Limitar retries a falhas puramente transitórias (max 1 retry com backoff curto) ou fail-fast com 502/504 imediato | Latência p95 superior ao SLO |
